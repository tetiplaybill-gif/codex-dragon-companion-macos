# 白龙桌宠 · macOS 社区版

在桌面查看 Codex 任务状态、完成提醒、本机 Token 用量和账户额度，并可按需下载白龙人物动画。

这是面向 **Apple Silicon Mac** 的第三方社区项目，与 OpenAI、Apple 无隶属关系。当前版本为 **1.0.1-mac.2-preview.1**，属于预览版。

[下载预览版](https://github.com/tetiplaybill-gif/codex-dragon-companion-macos/releases/tag/v1.0.1-mac.2-preview.1) · [安装与使用](docs/INSTALL.md) · [从源码构建](docs/BUILD.md) · [来源及许可](NOTICE.md)

## 开始使用

1. 在 Release 页面下载 Apple Silicon 安装包及同名 SHA-256 校验文件，按[安装说明](docs/INSTALL.md)验证。
2. 将应用放入“应用程序”后打开。安装包只含卡片界面；没有人物动画属于正常情况。
3. 在“设置 → 素材（角色与素材）”选择轻量画质，点击“下载并启用”。动画从素材原发布源按需下载并校验。
4. 打开已登录的 Codex 桌面应用；如连接异常，在“设置 → Codex → 检测连接与额度”查看各项状态。
5. 若希望随 Codex 启动，自行开启“随 Codex 桌面端启动”并点击“应用”。**新安装默认关闭启动联动**。

本版使用 ad-hoc 签名，未经过 Apple 公证，首次打开可能出现 macOS 安全提示。请仅按系统提供的正常确认流程处理；详见[首次打开](docs/INSTALL.md#首次打开)。

## 功能与数据

- **Codex 联动**：读取本机已有任务状态和用量，显示完成提醒；账户额度依赖本机 Codex 登录和 CLI 连接。不可用不会显示为零。
- **人物动画**：轻量素材独立下载，可调整大小、移动及动作设置；全屏让位时暂停被隐藏人物的动画，恢复后继续播放。
- **公开公告**：免 X 登录、免付费读取 [Codex Resets](https://codex-resets.com/) 的第三方重置汇总，以及 [Codex 官方更新记录](https://learn.chatgpt.com/docs/changelog)。各来源只显示最新一条，分别标注来源、时间和状态。
- **公告提醒**：默认每 15 分钟检查，可调整间隔或静音；首次同步、重复公告、未来安排及功能更新不响铃。只有确认属于新发生重置的公告才触发提醒。

公告会受到来源覆盖范围、缓存及网络延迟影响，**不是个人 X 账号的完整推文同步，也不证明你的账户额度已经到账**。账户实际余额请看“额度”页；失败时保留的旧值会标注为缓存。

桌宠设置、素材和本机统计缓存保存在当前用户的应用数据目录；不会随源码或安装包提供。连接和公告功能不要求额外模型 API 密钥。可选聊天服务是独立功能，需要使用者另行配置。

## 系统与验证范围

| 项目 | 范围 |
|---|---|
| 架构 | Apple Silicon / arm64；未提供 Intel 包 |
| 最低系统声明 | 当前构建配置声明 macOS 12.0；最终安装包的最低要求以 Release 说明为准 |
| 已验证系统 | macOS 27.0.1；不代表已覆盖所有较早版本 |
| 动画 | 安装包不内置，首次启用需要网络下载 |
| 签名 | ad-hoc，未 Apple 公证 |
| 更新 | 下载新 Release 手动更新；保留应用数据。应用内自动更新暂不可用 |

Python 运行时或依赖版本变化可能提高最低系统要求。预览版的验证记录以对应 Release 为准，不把源码测试通过当作所有机器安装成功的保证。
