# 本地构建产物使用说明

本仓库仅公开源码，不提供 `1.0.1-mac.2-preview.1` 的现成安装包。请先按[构建说明](BUILD.md)自行生成 Apple Silicon 应用，并阅读[本地验证范围](VALIDATION.md)。

## 放置自己的构建产物

在构建输出目录找到 `BailongEnhanced.app`（显示名称“白龙桌宠”），复制到“应用程序”后从那里启动。若以前装过桌宠，先退出旧实例并保留应用数据，再替换应用。

如果自行使用 `--dmg` 生成磁盘映像，可核对同时生成的 SHA-256 文件，再打开映像并把应用拖入“应用程序”。不要一直从磁盘映像运行。自行构建产生的哈希只用于识别你的文件，不等于 Apple 公证或安全审计；这里没有承诺可下载的本仓库 DMG。

## 首次打开

按上述脚本自行构建的应用采用 ad-hoc 签名，未经过 Apple 公证。macOS 可能要求确认来源：如果系统提供，可在 Finder 中按住 Control 点按应用并选择“打开”，或在“系统设置 → 隐私与安全性”查看对应的“仍要打开”选项。只有确认源码及依赖来源、自行构建的文件和提示内容后才继续。

若系统提示应用已损坏、含恶意软件，或没有正常确认入口，请停止并反馈具体提示。**不要关闭 Gatekeeper，不要清除 quarantine 属性，不要运行来源不明的修复脚本。** 本项目不要求改变这些系统安全设置。

按 `--cards-only` 构建后，首次只有卡片而没有人物是正常的。

## 下载人物动画

打开桌宠“设置 → 素材”（完整名称为“角色与素材”），选择轻量画质并点击“下载并启用”。下载会使用素材原发布源并校验文件；有现有动作时会等待合适边界再切换。

素材和程序分开保存，升级通常可以复用。下载失败时卡片仍可使用；保留错误提示，稍后重试。不要手动覆盖动画清单或关闭校验。

## 连接 Codex

先正常安装并登录 Codex 桌面应用。桌宠读取本机任务及用量，并通过现有 Codex CLI 连接读取账户额度，不需要为这些功能配置聊天 API 密钥。

在“设置 → Codex → 检测连接与额度”查看任务、额度等独立状态。自动识别失败时，可展开“连接路径与检测报告”，选择本机“Codex 数据目录”或“Codex CLI 程序”，点击“验证并保存路径”，再重启桌宠。不要复制或提交登录凭据来排查问题。

## 随 Codex 启动与停止

新安装默认不启用启动联动。在“设置 → Codex → 启动与退出”开启“随 Codex 桌面端启动”，点击“应用”。它注册当前用户的轻量监听，在检测到 Codex 桌面应用运行时启动桌宠。该功能识别 Codex 桌面应用，不以名称相似的 ChatGPT 或其他应用代替。

“登录 macOS 时启动”是独立选项，会在登录时直接启动桌宠；只需要随 Codex 启动时，无需开启它。“Codex 桌面端关闭后退出桌宠”也单独选择，确认 Codex 退出后约 6 秒生效。

启用联动后，macOS 可能提示新增后台项目，可在“系统设置 → 通用 → 登录项与扩展”查看。手动退出桌宠后，本次 Codex 运行期间不会反复拉起；需要时可以手动重新打开桌宠。

停用时，将“随 Codex 桌面端启动”和不再需要的“登录 macOS 时启动”关闭，再点击“应用”。随后从菜单选择“退出”或“退出桌宠”。请在系统已完成保存后再移动或删除应用。

## 公告与声音

点击卡片中的“公告”，或使用“设置 → Codex → 打开公告与提醒设置”。公开来源无需 X 账号或付费订阅：

- [Codex Resets](https://codex-resets.com/) 是第三方重置汇总，只覆盖其收录的重置公告；页面保留署名，原始 X 链接由该来源提供。
- [Codex 官方更新记录](https://learn.chatgpt.com/docs/changelog) 提供产品更新，保持静音。

默认 15 分钟检查一次，各来源分别显示状态、上次成功时间和最新一条。可调整“检查间隔”，关闭“明确重置公告响铃”，或点击“立即静音”；普通设置修改后点击“保存公告设置”。来源或网络失败时显示缓存，不保证即时到达。公告不代表本机账户额度到账，也不覆盖某个个人账号的全部推文。

## 保留数据的更新与卸载

更新时获取新的源码并重新构建，先退出桌宠，再用新构建产物替换“应用程序”中的应用；应用数据目录不随之删除。如果移动了安装位置，重新打开应用并检查启动联动设置。

卸载时先在设置中关闭两个启动选项并“应用”，退出桌宠，然后在 Finder 中把应用移到废纸篓。以下数据目录会保留，方便以后重装：

```text
~/Library/Application Support/BailongEnhanced/
```

不要删除 Codex 自己的数据目录。若希望清理桌宠数据，先自行备份并确认其中的设置、下载素材和缓存是否还需要，再通过 Finder 单独处理；卸载不要求执行批量删除命令。

若应用已无法打开，可先在系统的“登录项与扩展”中停用对应后台项目，并反馈启动问题。不要为了卸载而终止正在工作的 Codex 任务或删除其登录数据。
