# LGPL 动态库与本地重建

本源码提供的构建方式采用 PyInstaller onedir/macOS bundle 布局；若据此生成应用，Qt/PySide/Shiboken 是 `Contents/Frameworks/` 下的独立库、framework 和插件。这个布局使库文件可以单独检查和替换；它本身不等于已经证明所有兼容修改版本均能运行。

本项目的许可说明不限制用户修改所用 LGPL 库，以及为调试这些修改而进行逆向工程的 LGPL 权利。该保留仅针对适用库，不自动为角色美术或其他无关材料授予新许可。

## 可核对的替换范围

- PySide6 扩展模块和 `libpyside6.abi3.6.9.dylib`。
- Shiboken 扩展模块和 `libshiboken6.abi3.6.9.dylib`。
- QtCore、QtGui、QtWidgets、QtNetwork、QtDBus、QtSvg framework，以及所使用的对应插件。
- 必要的依赖库、版本和加载路径，必须一并保持兼容；不能仅换一个名称相同但 ABI 不兼容的文件。

请在独立测试副本中进行修改，保留原应用和数据。使用同版本源码时，需按官方构建说明选择 Apple Silicon、相容的 CPython/PySide ABI 和 Qt 6.9.2 接口，并保留相关版权及许可。完整应用源码与构建脚本随本版本仓库提供；本项目没有为这些源码或每种编译配置承诺重建结果完全一致。

macOS 会校验代码签名；修改库可能使应用现有签名失效。签名处理必须针对用户拥有的修改副本，并遵守所用系统的正常签名与安全策略。本说明不要求关闭 Gatekeeper、移除 quarantine、改动 Codex/ChatGPT 本体或扩大系统权限。
